✍️ 일기 생성
문체·어투·키워드를 바꾸고 🔄 다시 생성을 누르면, 사진을 다시 고르지 않고 같은 사진으로 새 일기를 써줍니다. ✍️ 정현체는 직접 쓴(📝 수동) 일기의 문체·어투를 학습해 똑같이 써줘요(수동 일기가 없으면 기본 예시 사용). 📖 내 일기 문체는 저장된 최근 일기 전반의 말투를 따라 씁니다.
📅 여러 날 한 번에 (밀린 일기) — 펼치기
밀린 며칠치를 한 번에 만듭니다. 구글 포토는 여러 날 사진을 한 번에 고르면 촬영일별로 묶어 각각 일기를 씁니다. 드라이브는 아래 기간(시작~끝) 안의 날짜마다 씁니다. 이미 일기가 있는 날은 건너뜁니다. 위의 문체·어투 설정이 함께 적용됩니다.

⚙️ API 연동 설정

켜면 로그인 권한에 generative-language scope가 추가됩니다. GCP에서 ① Generative Language API 활성화 ② 동의화면에 scope 등록 후 저장 → 재로그인 필요. 준비 전이면 API 키로 자동 폴백됩니다.
'구글 포토'는 드라이브 자동업로드 없이 포토 창에서 바로 고릅니다. 단, 포토 사진은 만료 주소라서 저장된 일기 히스토리의 썸네일은 보관되지 않습니다(텍스트는 영구 보관). '드라이브'는 기존 방식(yyyy-MM 폴더의 그 날짜 사진 자동수집).
주간 요약을 본문으로 가져오고, 운동/공부/주요 활동은 의미 있는 값일 때만 꼬리표로 붙입니다. 이미 일기가 있는 날짜는 건너뜁니다.
~
읽기 권한(drive.readonly)으로 사진만 가져옵니다. 일기는 브라우저에 표시되며, 저장은 복사/다운로드로 합니다.
저장된 모든 일기를 한 파일로 내려받습니다. 시트를 잃거나 다른 곳으로 옮길 때의 안전장치예요. (사진은 포함되지 않고 텍스트만)
다른 기기로 옮기거나 백업할 때 사용하세요. 한 줄 코드로 복사·붙여넣기됩니다.
